# 博客标签功能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给博客文章增加平铺多标签，提供 `/tags/` 索引页与 `/tags/<slug>/` 列表页，并在文章页与导航中暴露标签。

**Architecture:** 标签存在 content collection 的 `tags` 字段里（英文、可选、默认空数组）。新增 `src/lib/tags.ts` 做聚合与 slug 化，新增 `src/components/PostList.astro` 抽出首页列表供标签页复用，新增两个标签路由页。文章页与 Header 做小改动。

**Tech Stack:** Astro 7（content collections + `getStaticPaths`）、TypeScript、纯静态输出（`base: /blog`）。

**Spec:** `docs/superpowers/specs/2026-10-15-tags-design.md`

## Global Constraints

- 站点 `base` 为 `/blog`；所有内部链接用 `import.meta.env.BASE_URL.replace(/\/$/, '')` 拼前缀（与现有代码一致）。
- 标签为英文，URL slug = 标签小写、空格转 `-`（`RouterOS` → `routeros`）。
- `tags` 字段可选、默认 `[]`，缺 tags 的文章必须能正常构建。
- 页面外壳统一用 `src/layouts/BaseLayout.astro`（`lang="zh-CN"`）。
- 不新增运行时依赖；不改 RSS、首页列表语义、文章正文。
- 验证一律本地 `npm run build` + 检查 `dist/`，不核对线上。
- 提交信息用英文祈使句，与仓库现有风格一致。

## Review Focus

- **标签名含空格或大小写**（如 `WebDAV`、`Home Lab`）：`slugifyTag` 必须产出稳定的 URL slug，且同一标签在不同文章里映射到同一页面。
- **无标签的文章**：`tags` 缺省时构建不报错，文章页不渲染空标签区。
- **URL 前缀**：标签链接必须带 `/blog` 前缀，否则线上 404。
- **只有 1 篇文章的标签**：页面仍正确渲染（不要假设 ≥2 篇）。
- **About 页**：不传 `tags` 时 `BlogPost.astro` 不得报错、不得显示标签区。

### Task 3: 标签辅助函数 + 标签索引页 + 单标签页

**Files:**
- Create: `src/lib/tags.ts`

**Interfaces:**
- Consumes: `PostList`（Task 2）
- Produces:
  - `slugifyTag(tag: string): string`
  - `getAllTags(): Promise<{ tag: string; slug: string; count: number }[]>`（按 count 降序，再按 tag 升序）
  - `getPostsByTag(slug: string): Promise<CollectionEntry<'blog'>[]>`

- [ ] **Step 1: 写“测试”——确认标签页还不存在**

Run: `Test-Path dist/tags/index.html`
Expected: False

- [ ] **Step 2: 创建 `src/lib/tags.ts`**

```ts
import { getCollection, type CollectionEntry } from 'astro:content';

export function slugifyTag(tag: string): string {
  return tag.trim().toLowerCase().replace(/\s+/g, '-');
}

export async function getAllTags() {
  const posts = await getCollection('blog');
  const counts = new Map<string, number>();
  for (const p of posts) for (const t of p.data.tags ?? []) counts.set(t, (counts.get(t) ?? 0) + 1);
  return [...counts.entries()]
    .map(([tag, count]) => ({ tag, slug: slugifyTag(tag), count }))
    .sort((a, b) => b.count - a.count || a.tag.localeCompare(b.tag));
}

export async function getPostsByTag(slug: string): Promise<CollectionEntry<'blog'>[]> {
  const posts = await getCollection('blog');
  return posts
    .filter((p) => (p.data.tags ?? []).some((t) => slugifyTag(t) === slug))
    .sort((a, b) => b.data.pubDate.valueOf() - a.data.pubDate.valueOf());
}
```
